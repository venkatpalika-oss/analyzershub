Yokogawa OX400 — Sample Path / Former Probe-Fouling Guidance

The former insertion-depth, ash-cap and purge-frequency instructions described a boiler probe, not the documented OX400. Do not use those instructions to service this instrument. Sample-path service requires the installed configuration manual.

Configuration scope

OX400 measures sampled gas using a zirconia sensor. Use the installed model code and sample-drawing option when choosing documentation.

Detailed fault isolation remains subject to separate technical review. This page does not authorize component replacement from a symptom alone.
