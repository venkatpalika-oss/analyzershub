Decision Tree – ZR22G No Oxygen Signal

  • No Oxygen Signal Alarm
    • Is heater temperature stable?
      • No → Resolve heater issue first
      • Yes → Check reference air flow
        • No flow → Restore reference air supply
        • Flow OK → Check probe output signal
          • No output → Continue sensor and circuit diagnostics before authorizing replacement
          • Output present → Check converter input terminals
            • Signal missing → Repair wiring
            • Signal OK → Continue converter diagnostics; this check alone does not establish electronics failure

Field Tip: Reference-air arrangements differ; identify the installed configuration before troubleshooting.
