Yokogawa OX400 — Heater Error

The earlier generic heater LED, resistance and replacement sequence was not matched to an OX400 service manual. A heater-related indication requires the applicable OX400 diagnostic and service instructions.

Configuration scope

OX400 measures sampled gas using a zirconia sensor. Use the installed model code and sample-drawing option when choosing documentation.
