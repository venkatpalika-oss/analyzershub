ABB AZ25 — Alarm Documentation

AZ25 uses a zirconium oxide cell for in-situ oxygen measurement. The previous TDLAS identity and beam-loss, optical-alignment and laser-window guidance did not describe this product and have been withdrawn.

Use the installed AZ25 probe and transmitter manuals for alarm identification. A model-matched alarm-code and corrective-action review is still required; no replacement decision tree is supplied here.
